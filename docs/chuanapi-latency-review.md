# Gemini 首字延迟：测量、优化与代码审查

基线：fork 提交 `344340d7c9d5652bb5d52aa0187971b82ab8321f`。覆盖模型目录/账号路由、上下文与工具、三种 API 的传输/终态、数据库与管理接口、认证/附件/媒体和发布门禁。以下是源码和隔离测试结果，不是生产安全认证，也不是所有依赖逐行审计。

## 这一轮的改动

- 只压缩工具 schema JSON 的格式空白；不删字段、不截断原始消息、不改变工具参数和结果。合成 30 工具样本的 schema 从 75,292 到 39,651 UTF-8 字节（-47.3%）。这不是实际请求的缩减率、计费 token 或首字提速。
- 在请求日志加入下列可空字段。历史未埋点和当前未发生均为 `null`，0 毫秒和附件 `false` 是正常观测。未保存提示词、工具 schema、附件内容或凭据。
- 仍保留型号验证和原有保活配置。普通正文通过校验后继续流式；不提前发可执行的工具完成事件。流式成功日志在最后的本地写入后采集，不把预发的 SSE 头当正文。
- 管理日志分页最多 500 行；查询异常不再返回看似完整的结果。后台表分列上游首行、正文首字、首个工具。
- 目录遇明确 XSRF 拒绝时只刷新一次；内部目录查询预算用完、调用者仍有效时可用未过期的已验证缓存，不影响后续实际型号校验。

| 日志字段 | 含义 |
|---|---|
| `catalog_ms` | 第一个账号目录查询本身的耗时；不等于全部选号准备 |
| `prepare_ms` | 单轮路径的上下文转附件准备耗时，不含客户端图片下载或全部请求准备 |
| `generation_start_ms` | 从请求进入到发起首个上游**生成提交**；WebChannel 握手和目录 RPC 不算生成提交 |
| `upstream_first_text_ms` | 到首个上游候选文本，可能是工具围栏内容；不是首行 TTFB |
| `model_verified_ms` | 到首次匹配的型号元数据；不保证之后不会收到冲突型号 |
| `downstream_first_text_ms` | 到第一个正文被代理写出；不等于终端实际收到的时间 |
| `first_tool_ms` / `first_reasoning_ms` | 首个完整工具事件本地写出／首个上游思考文本；二者不算正文首字 |
| `first_heartbeat_ms` | 首个保活，不算生成内容 |
| `prompt_bytes` / `prompt_budget_bytes` / `context_attachment_used` | 格式化 UTF-8 字节、阈值、是否走了额外上下文附件路径 |

这些是首个里程碑，跨换号不重置；分析对照时应排除已重试请求或单独分组。旧 `ttfb_ms` 保留，不与新字段混算。以同账户、模型、思考档和传输做短/长 × 有/无工具对照，单列首次目录刷新与热缓存，观察 P50/P95 与空值占比。长上下文看 UTF-8 字节，不以字符数推断是否过 `128000` 默认阈值。

## 其余发现（按影响排）

| 优先级 | 代码发现 | 下一步 |
|---|---|---|
| P1 | 默认对外监听，启用后台但空管理令牌时不校验身份（`config.go`、`admin.go`）。这是继承风险，未核实你的部署是否如此。 | 对外实例强制应用层认证，管理端仅限受控网络；在隔离环境验证后再改默认。 |
| P1 | 远程附件缺少目标网络边界，媒体重定向没有明确的凭据目标范围（`vision.go`、`media.go`）。只读审查，未进行攻击或真实服务探测。 | 统一下载边界和受控出站规则；在隔离环境验证合法图片/视频仍可下载。 |
| P1 | 可用目录扫描所有账号，但生成前置筛选最多试三个，可能漏掉后面的可用账号。能力落空时用首个账号的代理，可能重复查目录（`gemini.go`、`formal_model_policy.go`）。 | 将已知能力优先、未知候选搜索预算和实际生成重试区分，再按候选绑定选择出口。 |
| P1 | Responses 没有真正处理 `previous_response_id`；部分工具历史/图片输入被丢，混合正文/工具的流索引与最终数组不同（`server.go`、`messages.go`）。 | 先明确不支持的状态字段并修复工具往返、图文和索引，再谈提前工具事件。 |
| P1 | 既有多轮状态键不含租户、工具定义，且复用可变会话状态（`conversation.go`）。 | 并发与归属先过测试，再开放跨请求续接；不要为降首字默认打开多轮。 |
| P2 | 远程视频读取限额与后续视频校验不同，可能把截断内容当成功；附件下载/上传/媒体产物尚未完整透传取消（`vision.go`、`upload.go`、`media.go`）。 | 增加一致的分层大小预算、取消和完成判据。 |
| P2 | 日志每请求启动异步写入，缺有界队列/退出刷新；聚合日报不是全日真实 P95；镜像流水线缺统一测试门禁（`server.go`、`admin.go`、`.github/workflows`）。 | 用原始分段日志算分位数，规划有界写入和发布必跑测试。 |

不建议以关闭型号校验、已输出后重跑、并发投机请求或默认提前执行工具来降低表面首字。尚未用用户真实账号做前后 A/B；不能据此承诺 6–28 秒将降低到某个值。
