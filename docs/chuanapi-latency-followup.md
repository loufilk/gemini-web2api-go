# ChuanAPI Gemini：代码审查修复与升级提示

候选版本：`4.28.1+chuanapi.models2.latency2`，基于上一轮首字优化提交 `bd26ac2e23f17b10a9dd71f661bce34d1bbd4500`。此版本继续保留 Hydrogen/Carbon 名称、上游实际型号校验、15 秒 SSE 保活和已提交请求不盲目重放的原则。

## 修复

- **账号选择**：优先使用当前账号与出口有新鲜能力缓存、且支持请求型号/思考档的账号。已知不兼容的账号不消耗生成重试；未知候选单独限额（最多 8 个准备候选；严格型号的 XSRF/目录合计 24 秒预算，不含既有同步 Cookie 轮转自身的 HTTP 等待）。换号会按其出口偏好重新获取槽位。证据不足不伪装成模型不可用；目录明确不支持才返回对应不可用错误。
- **Responses**：保留工具调用与结果的 `call_id`、工具名和图文输入。SSE 输出序号与最终输出数组一致；不能在生成和型号确认成功前发出完整可执行工具调用。此适配器仍是无状态接口：每次附完整历史并用 `store:false`（可省略）。不接收非空的 `previous_response_id`、非空 `conversation`、显式 `store:true` 或无法取回的已存文件引用。
- **会话隔离**：停用按历史文本命中并复用上游会话的旧逻辑。旧 `multi_turn` 字段仍能被读取，但没有效果；不会覆盖临时对话配置。需要管理历史的客户端自行传历史，较长对话仍受输入限制。
- **后台**：未配置有效的 `ADMIN_TOKEN` 时管理 API 拒绝访问，生成 API 不受影响。正常 UI 会话与 `Authorization: Bearer` 保留，URL `?token=` 不再认证。统计范围设上限；长期汇总的分桶百分位均值不作为真实总体 P95 展示。
- **媒体**：外链素材只能访问默认 HTTP(S) 端口的公开地址；下载不带上游凭据，重新验证跳转和实际连接地址。上游产物凭据只发往已知 Google HTTPS 主机（`lh3.googleusercontent.com`、`work.fife.usercontent.google.com`、`contribution.usercontent.google.com`）。外链图片/视频上限分别 12/50 MiB，同次附件累计上限 100 MiB，单个产物上限 100 MiB，超限明确失败。同步媒体产物获取随调用者取消；每次 I/O 最多 90 秒，图片/音频、视频取回分别最多 2、8 分钟。异步视频任务在受理后独立运行。合法外链和 Google 实时 CDN 仍需在有权限的环境验收。
- **运行**：视频状态读取独立快照，消除后台更新与 JSON 序列化之间的竞态。请求日志改为有界诊断队列（最多积压 2048 行，拥堵时丢弃并汇报计数，不是账本）。停止进程时给 HTTP 最多 25 秒排空，再给日志最多 8 秒写回；容器宽限建议至少 40 秒。常规、竞态、静态检查和构建均纳入 CI，Docker/Release 发布工作流依赖检查通过。

## 灰度验证与回退

1. 固定候选提交，执行 `go test -count=1 ./...`、`go test -race -count=1 ./...`、`go vet ./...`、`go build ./...`。需镜像时从该 SHA 手工构建（默认 Compose 的 `latest` 是官方上游，不是本分支）。Compose 部署请提供强随机 `ADMIN_TOKEN`，通过可信 HTTPS/管理网络访问；不要把令牌放进 URL。
2. 隔离验证 New API 的 Hydrogen/Carbon 流式和非流式、401/503/真实降级、短/长上下文及工具历史。确认严格型号未匹配不出正文、已提交后无不确定重放。用同账号/同思考档真实 A/B 观察 P50/P95，不把保活或首行算正文首字。保留已有 15 秒保活和渠道 #157 两个模型；不要启用未验收的 Argon。
3. 对媒体测试合法外链及 Google 重定向、取消、上限失败；对 Responses 测试显式储存/续接被拒是否符合客户端预期。注意旧的无令牌后台及历史自动续接是刻意停用的，不应通过关掉型号校验来规避。
4. 参考[模型修复回退说明](chuanapi-model-rollout.md)，回退到现场记录的上一个可用定制镜像 digest，不能切到官方 v4.28.1 或 `latest`。先隔离候选流量，不改 #157 分组，不删除数据库兼容列；升级和回退均需备份、验收后再放量。

以上是待灰度的开发结果；不代表已部署、已验证真实账号或已证明线上首字提速。
